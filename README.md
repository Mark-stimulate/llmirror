# 词镜 llmirror

**可自托管的大模型 API 实测工作台。** 从自己的测试节点发出流式请求，记录首输出延迟、单请求生成速度、完整响应率和模型回答，适合接口接入验收、日常巡检和故障复盘。

## 功能

- **模型巡检**：按模型定时采样，也可立即巡检全部已接入模型。按时间范围查看延迟、吞吐和可靠性的趋势。
- **性能测试**：使用日常聊天、知识库问答、智能体工作流的预设，或提交脱敏案例。
- **能力回归**：用固定题目对比同一个模型在不同时间的回答表现，本地评分并保留样本。
- **团队协作**：接口按平台分组，支持批量添加模型、临时接口、角色权限、批量删除记录和脱敏 CSV 导出。
- **本机存储**：FastAPI 后端、原生网页和 SQLite，支持 Windows 与 Linux。

## 开始使用

安装 Python 3.11+，克隆仓库并进入项目目录。首次启动会创建虚拟环境并下载依赖。

```bash
git clone https://github.com/Mark-stimulate/llmirror.git
cd llmirror
```

| 系统 | 启动方式 |
| --- | --- |
| Windows | 双击 `start.bat` |
| Linux | 运行 `bash start.sh`，需要 Python 的 venv 和 pip |

1. 在部署机器上打开 `http://127.0.0.1:8765`，创建管理员账号。远程 Linux 可以先用 SSH 端口转发访问部署机器的本地端口。
2. 到「接口管理」填写 OpenAI 兼容接口的 Base URL、模型 ID 和 API Key。
3. 从「发起测试」运行快速测试，查看「测试记录」。需要持续监测时，再为相应模型配置定时巡检。

Windows 可执行文件的构建步骤见 [构建说明](tools/BUILD.md)。如需管理 Windows 后台服务，可使用仓库内的 PowerShell 脚本和服务配置，另行准备 WinSW 2.12.0 并命名为 `llmirror-service.exe`，与 `llmirror.exe` 放在同一目录。

## 指标口径

| 指标 | 含义 |
| --- | --- |
| 首输出延迟 | 从请求发出到第一段有效思考或正文，界面同时记录正文首输出 |
| 生成速度 | 基于流式响应和服务商返回的输出 tokens 估算单请求生成速度，缺少有效用量时留空 |
| 完整响应率 | 完整、非空且未截断或过滤的响应占已尝试请求的比例，主动取消排除 |

横向对比时请对齐测试节点、输入、版本和思考模式。少量巡检结果只能说明这批请求的表现。模型费用以接口平台结算为准，定时巡检默认关闭。

## 部署与数据

首次运行会生成 `server.json` 和 `data/`。升级时停止服务并保留这两项。迁移时要一同保留数据库和 `vault.key`。公网访问应通过配置妥当的 HTTPS 反向代理。

Windows 可用 `start.bat --backup` 备份，Linux 可用 `bash start.sh --backup`。排查问题时，请在 GitHub Issues 中提供版本、复现步骤和脱敏日志。
